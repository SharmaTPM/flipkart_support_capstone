  3. "How many days will delivery take in Bangalore?"

  5. "Can I return a product if the pickup pincode changes?"

Evaluation Metrics:
  Relevant documents per query identified at source level (not chunk level)
  Top-3 chunks retrieved from Faiss
  Chunks deduplicated back to parent document_id
  Intersection calculated
  Per-query Precision@3 and Recall@3 computed
  Mean averages calculated

Per-Query Arithmetic (Example):
  Query 1: "How long do I have to return a pair of shoes?"
  Ground Truth: [doc_1]
  Retrieved Chunks: [chunk_from_doc_1, chunk_from_doc_3, chunk_from_doc_5]
  Retrieved Docs: [doc_1, doc_3, doc_5]
  Relevant Found: [doc_1]
  Precision@3 = 1 / 3 = 0.3333
  Recall@3 = 1 / 1 = 1.0000

Scoring at Document Level:
  ✓ Each retrieved chunk mapped to parent document
  ✓ Duplicates removed (only unique doc_ids counted)
  ✓ Evaluation against document-level ground truth
  ✓ NOT evaluated at chunk level

Code Structure (evaluate_rag.py):
  - Loop through RAG_GROUND_TRUTH items
  - For each query, retrieve top-3 chunks
  - Deduplicate to parent documents
  - Calculate precision: relevant_found / retrieved_count
  - Calculate recall: relevant_found / ground_truth_count
  - Accumulate lists and compute means
